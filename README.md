# Who Wants to Be a Millionaire?

## Overview

Welcome to my Who Wants to Be a Millionaire project repository! This website was created to simulate the famous TV Game Show, "Who Wants to Be A Millionaire?". Players are able to go through levels, with questions getting harder as they progress just as players do in the real life game. There is also a leaderboard system that allows players to see others scores as well as their own. 

## Tech Stack

- **HTML**: Markup language used for creating the structure of the webpages.
- **CSS**: Sytlesheet language for designing the webpages.
- **PHP**: Server-side scripting language which added interactive elements to the website such as the questions, login/logout feature, and scoreboard.
- **IDEs**: Notepad++

## Key Features

- **Login/Logout**: Players are allowed to login and logout of accounts, which holds all of their data.
- **Registration Form**: Users can register for a new account which will allow them to later login an access the Who Wants to Be a Millionaire game.
- **Scoreboard**: Players scores are stored in a txt file which is used to help display the scores on a scoreboard. The top 4 scores are displayed in descending order.
- **Data Storage**: A text file is used to store all of users data, such as usernames, passwords, money won, and score amount. PHP is used to get all data from this file to do all the tasks of the website. Such as display the scores, confirm login information, register accounts, etc.
